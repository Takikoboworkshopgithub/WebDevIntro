01：HTML / CSS

1. 環境設定

今回の講習では、Visual Studio Code（VS Code）を使ってWebページを作成します。

まず、VS Codeを開き、次の拡張機能をインストールしてください。

  • Live Server：作成したWebページをブラウザで表示し、変更を確認するための拡張機能
  • Prettier - Code formatter：HTMLやCSSなどのコードのインデントや改行を整えるための拡張機能

VS Codeの左側にある拡張機能アイコンをクリックし、名前を検索してインストールします。

作業用ディレクトリを作成する

適当な場所でターミナルを開き、次のコマンドを実行してください。

mkdir 01
cd 01
code .

code . は、現在のディレクトリをVS Codeで開くコマンドです。

VS Codeで新しいファイルを作成し、index.html という名前で保存してください。

※ touch index.html でファイルを作成してから code . を実行しても構いません。Windowsの環境によっては、ファイルの作成方法が異なる場合があります。

2. HTMLを書いてみよう

index.html を開き、エディタ上で ! を入力してEnterキーを押してください。

次のようなコードが自動で入力されたはずです。

<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body></body>
</html>

これはHTML文書の基本的なひな形です。VS CodeのEmmetという機能が、HTMLの基本構造を自動で生成してくれました。

毎回すべてを手入力する必要はありません。このひな形をもとに、必要な内容を追加していきます。

HTMLの基本構造

  • <!doctype html>：HTML文書であることをブラウザに伝える
  • <html>：HTML文書全体を囲む
  • <head>：文字コードやページタイトルなど、文書に関する情報を書く
  • <body>：ブラウザのページ本体に表示する内容を書く
  • <title>：ブラウザのタブなどに表示するページタイトルを指定する

実際にページの内容を記述するのは、基本的に<body>と</body>の間です。

また、<meta charset="UTF-8" /> は文字コードを指定し、日本語などの文字を正しく扱うために使います。<meta name="viewport" ...> は、スマートフォンなどの画面幅に合わせてページを表示するための設定です。

Webページは何でできている？

Webページを作るうえで、まず押さえておきたい技術がHTMLとCSSです。

HTML（HyperText Markup Language）

Webページの構造や内容を記述します。見出し、文章、画像、リンクなどを配置します。

CSS（Cascading Style Sheets）

Webページの見た目を指定します。文字の色や大きさ、背景、余白、配置などを調整します。

例えば、HTMLで見出しを作り、CSSでその見出しを大きくしたり、色を付けたりします。

3. 実際にHTMLを書いてみよう！

以下のコードをindex.htmlに入力してください。

<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <h1>これはh1タグです。見出しに用います。</h1>
    <h2>これはh2タグです。小見出しに用います。</h2>
    <h3>これはh3タグです。さらに下位の見出しに用います。</h3>
    <p>これはpタグです。段落を書くのに用います。</p>

    <!-- これはコメントです。ブラウザには表示されません。 -->

    <!-- 以下は使用例 -->
    <h1>プログラミングサークル「IQ」</h1>

    <h2>競プロ</h2>
    <p>競技プログラミングに興味のあるメンバーで構成されています。</p>
    <p>ICPCに向けてコーディング力を鍛えます。</p>

    <h2>Web</h2>
    <p>Web開発に興味のあるメンバーで構成されています。</p>
    <p>IQのシステムを制作するチームです。</p>

    <h2>ゲーム</h2>
    <p>ゲーム開発に興味のあるメンバーで構成されています。</p>
    <p>Unityを用いてゲームを開発しています。</p>
  </body>
</html>

入力できたら、ファイルを保存してLive Serverで表示してみましょう。

index.htmlを右クリックし、Open with Live Serverを選択してください。ブラウザが開き、HTMLの内容が表示されます。

以降、コードを変更して保存すると、ブラウザにも変更が反映されます。

4. タグと要素

HTMLでは、<h1>や<p>のような記法を使って、文章に意味や構造を与えます。 

<h1>こんにちは！</h1>

このとき、用語を整理しておきましょう。

  • タグ：<h1>や</h1>のような記述
  • 要素：開始タグ、内容、終了タグなどから構成されるまとまり

つまり、上の例では<h1>が開始タグ、こんにちは！が内容、</h1>が終了タグであり、全体がh1要素です。

HTMLの要素には、それぞれ意味や役割があります。

セクション見出し：h1〜h6

見出しを表す要素です。

<h1>大見出し</h1>
<h2>小見出し</h2>
<h3>さらに下位の見出し</h3>

h1からh6まであり、数字が大きいほど下位の見出しを表します。

単に文字を大きくするためではなく、文書の見出し構造を表現するために使います。文字の大きさや色は、あとでCSSを使って調整できます。

段落：p

文章の段落を表す要素です。

<p>これは一つ目の段落です。</p>
<p>これは二つ目の段落です。</p>

段落ごとにp要素で囲みます。ブラウザでは通常、段落の前後に余白が設けられます。

コメント

HTMLには、ブラウザに通常表示されないコメントを書くことができます。

<!-- これはコメントです -->

メモや説明を残したい場合に便利です。VS Codeでは、選択した行に対してコメントの切り替え操作を使うこともできます。

5. ネスト：タグの中にタグを入れる

HTMLでは、ある要素の中に別の要素を入れることができます。これをネスト（入れ子構造）といいます。

例えば、文章の一部を強調したい場合は、p要素の中にstrong要素を入れます。

<p>
  C++というプログラミング言語には、<strong>プラス記号が2つ</strong>
  使われています。
</p>

strong要素は、内容が重要であることを表します。ブラウザでは通常、太字で表示されます。

同じように、mark要素を使うと、文章の一部をマーカーで強調するように表示できます。

<p>
  C言語から派生した言語にはC++のほかに、
  <mark>Objective-C</mark>があります。
  また、Objective-CとC++を組み合わせたObjective-C++もあります。
</p>

markは、文章の中で特に注目してほしい箇所を示すための要素です。

ネストの注意点

開始タグと終了タグの順序に注意してください。

<p>
  これは<strong>正しい書き方</strong>です。
</p>

次のように、要素の開始と終了の順序が交差する書き方は正しくありません。

<p>
  これは<strong>正しくない書き方です。
</p>
</strong>

入れ子にした要素は、基本的に内側から閉じます。

6. 改行

HTMLでは、ソースコード上で改行しても、ブラウザ上では通常、単なる空白として扱われます。

例えば、次のコードを実行してみてください。

<p>
  これは一行目です。
  これも一行目です。
</p>

HTMLファイルでは2行に分かれていますが、ブラウザでは同じ段落の文章として表示されます。

改行したい場合は、br要素を使います。

<p>
  これは一行目です。<br />
  これは次の行です。
</p>

brは、文章の途中で改行を表す要素です。終了タグを持たない要素の一つです。

ただし、段落を分けたい場合はbrを繰り返すのではなく、p要素を分けるのが基本です。

また、文章上の改行はHTML、要素間の余白は基本的にCSSで調整するという使い分けを覚えておきましょう。

7. リンクを作ろう

Webページの重要な機能の一つが、別のページへ移動するためのリンクです。

リンクにはa要素を使います。

別のHTMLファイルに移動する

まず、現在の01ディレクトリの中に、sampleというフォルダを作成してください。

01/
├── index.html
└── sample/
    └── index.html

sample/index.htmlに、次のコードを書きます。

<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>移動先のページ</title>
  </head>
  <body>
    <h1>移動しましたね！</h1>
  </body>
</html>

次に、最初のindex.htmlのbody内に、次のコードを追加してください。

<p>
  ページを移動してみましょう。
  <a href="./sample/index.html" target="_blank">ここをクリック</a>
  してみましょう。
</p>

リンクをクリックすると、移動先のページが新しいタブで開きます。

ここで使われている属性について説明します。

  • href：リンク先のURLやファイルパスを指定する
  • target="_blank"：リンク先を新しいタブやウィンドウで開くよう指定する

./sample/index.htmlは、現在のHTMLファイルがあるディレクトリを基準にした相対パスです。

外部サイトへ移動する

hrefには、外部サイトのURLも指定できます。

<p>
  これは
  <a
    href="https://info.cern.ch/hypertext/WWW/TheProject.html"
    target="_blank"
    rel="noopener noreferrer"
  >
    世界で最初期のWebサイト
  </a>
  の紹介です。
</p>

このリンクは、World Wide Webの初期の歴史を紹介するページへ移動します。

target="_blank"を使う場合、rel="noopener noreferrer"を付ける書き方が推奨されます。リンク先のページが元のページを操作するリスクを抑え、参照元情報の送信も防ぎます。

属性とは？

今までの要素と少し違い、タグの中にhrefやtargetなどの指定が登場しました。

このような追加情報を属性（attribute）といいます。

<a href="./sample/index.html" target="_blank">ここをクリック</a>

この例では、hrefとtargetが属性名で、それぞれの値がリンク先と開き方を指定しています。

属性は、要素の種類に応じて使い分けます。例えば、a要素ではhrefを使ってリンク先を指定し、img要素ではsrcを使って画像ファイルを指定します。

同じページ内で移動する

a要素は、別のページだけでなく、同じページ内の特定の位置にも移動できます。

<p><a href="#">ページの先頭へ移動</a></p>

<p><a href="#Section_further_down">下の見出しへ移動</a></p>

<!-- リンク先の見出し -->
<h2 id="Section_further_down">さらに下のセクション</h2>

ここでは、id属性で移動先の要素に名前を付けています。

href="#Section_further_down"は、そのidを持つ要素へ移動するリンクです。idは、同じHTML文書内で重複しないように指定します。

なお、href="#"はページ先頭付近への移動に使われることがありますが、厳密には空のフラグメントを指定する記法です。ページ内の特定の位置へ移動したい場合は、idを指定する方法を使いましょう。

8. 画像を表示しよう

Webページでは、文章だけでなく画像も表示できます。画像にはimg要素を使います。

01ディレクトリの中に画像ファイルを置き、次のように記述してください。

<img src="./sample.jpg" alt="サンプル画像" />
  • src：画像ファイルのパス
  • alt：画像の内容を説明する代替テキスト

画像が表示されない場合は、ファイル名やパスが正しいか確認してください。

img要素は終了タグを持ちません。また、画像の大きさはCSSで調整できます。

<img
  src="./sample.jpg"
  alt="サンプル画像"
  width="300"
/>

width属性を使って幅を指定することもできます。画像の見た目やレイアウトを細かく調整する方法は、CSSで学びます。

9. リストを作ろう

複数の項目を列挙したい場合は、リストを使います。

箇条書き：ulとli

<h2>趣味</h2>
<ul>
  <li>プログラミング</li>
  <li>音楽制作</li>
  <li>3DCG</li>
</ul>
  • ul：順序を持たないリスト
  • li：リストの各項目

番号付きリスト：olとli

<h2>Webサイトを作る手順</h2>
<ol>
  <li>HTMLを書く</li>
  <li>CSSを書く</li>
  <li>ブラウザで確認する</li>
</ol>

olは順序付きリストです。ブラウザでは通常、項目に番号が付きます。

単に見た目を整えるためだけではなく、内容が箇条書きなのか、順番のある手順なのかに応じて使い分けます。

10. CSSで見た目を変えよう

ここまではHTMLを使って、見出しや文章、リンク、画像などの構造を作ってきました。

次はCSSを使って、ページの見た目を変更してみましょう。

HTMLに直接CSSを書く

HTMLの要素には、style属性を使って直接スタイルを指定することもできます。

<h1 style="color: red;">赤い見出し</h1>

これで見出しの文字色が赤になります。

ただし、ページ全体の見た目を管理する場合、HTMLとCSSを分離した方が修正しやすくなります。

CSSの基本構文

index.htmlのhead内に、次のようなstyle要素を追加してみましょう。

<style>
  h1 {
    color: blue;
    font-size: 40px;
  }
</style>

h1要素の文字が青く、大きく表示されるようになります。

CSSは基本的に、次の構造で記述します。

セレクタ {
  プロパティ: 値;
}
  • セレクタ：どの要素にスタイルを適用するか
  • プロパティ：何を変更するか
  • 値：どのように変更するか

例えば、color: blue;は文字色を青に指定しています。

HTMLとCSSを分離する

実際のWeb開発では、CSSを別のファイルに分けて管理することが一般的です。

01ディレクトリにstyle.cssを作成し、次のコードを書いてください。

body {
  background-color: #f5f5f5;
  color: #333333;
  font-family: sans-serif;
}

h1 {
  color: #6750a4;
  font-size: 36px;
}

h2 {
  color: #008577;
}

p {
  font-size: 18px;
  line-height: 1.8;
}

次に、index.htmlのhead内に以下を追加します。

<link rel="stylesheet" href="./style.css" />

HTMLとCSSのファイルは、次のようになります。

01/
├── index.html
├── style.css
└── sample/
    └── index.html

保存してブラウザを確認してください。背景色、文字色、文字サイズなどが変更されているはずです。

よく使うCSSプロパティ

プロパティ 役割 例
color 文字色 color: red;
background-color 背景色 background-color: #eeeeee;
font-size 文字サイズ font-size: 20px;
font-weight 文字の太さ font-weight: bold;
text-align 文字の配置 text-align: center;
margin 要素の外側の余白 margin: 20px;
padding 要素の内側の余白 padding: 16px;
width 幅 width: 300px;
height 高さ height: 200px;

marginとpaddingの違い

marginとpaddingは、どちらも余白に関するプロパティですが、役割が異なります。

  • margin：要素の外側の余白
  • padding：要素の内側の余白

例えば、次のCSSを追加してみましょう。

h1 {
  background-color: #eaddff;
  padding: 20px;
  margin: 30px;
}

見出しの背景色が付き、文字の周囲に内側の余白ができ、さらに要素の外側にも余白ができます。

余白の調整はWebデザインで頻繁に使うため、この違いを理解しておきましょう。

11. ブラウザの開発者ツールを使おう

Web開発では、ブラウザに備わっている開発者ツールをよく使います。

ページをブラウザで開き、F12キーを押してみましょう。

Elements（要素）などのタブでは、HTMLの構造や適用されているCSSを確認できます。

例えば、表示中の見出しを選択してCSSの値を変更すると、その場で見た目が変わります。

この変更は、通常、HTMLやCSSのファイルには自動保存されません。ファイルにも反映したい場合は、VS Codeで編集して保存してください。

開発者ツールは、表示が想定どおりにならない場合に原因を調べるためにも役立ちます。

12. 演習：自分のプロフィールページを作ろう

ここまで学んだ要素を使って、自分だけのWebページを作成してください。

テーマは自由です。プロフィール、好きなゲーム、音楽、大学、趣味、架空のゲーム公式サイトなど、好きな題材を選んで構いません。

必須条件

  • h1要素でページの見出しを作る
  • h2要素で小見出しを作る
  • p要素で文章を書く
  • ulまたはolでリストを作る
  • a要素でリンクを作る
  • 画像を1枚以上表示する
  • CSSを使って文字色や背景色を変更する
  • marginまたはpaddingで余白を調整する

発展課題

  • 見出しを中央揃えにする
  • ページ全体の背景色を変更する
  • リンクをクリックすると別ページへ移動するようにする
  • セクション内リンクを作成する
  • 自分で調べたCSSプロパティを1つ以上使う

完成したら、Live Serverで表示し、意図したとおりに表示されているか確認してください。

13. まとめ

今回学んだことを振り返りましょう。

  • HTMLは、Webページの構造や内容を記述するための言語
  • CSSは、Webページの見た目を指定するための言語
  • タグを使って要素を記述する
  • 要素の中に別の要素を入れることをネストという
  • 属性によって、要素に追加情報を指定できる
  • a要素でリンクを作り、img要素で画像を表示できる
  • CSSでは、セレクタ・プロパティ・値を使ってスタイルを指定する
  • HTMLとCSSは別ファイルに分けて管理できる
  • Live Serverと開発者ツールを使うと、ページの表示を確認しながら開発できる

HTMLとCSSの基本を理解したら、次は作成したWebページをGitHubで管理し、インターネット上に公開する方法を学んでいきます。
