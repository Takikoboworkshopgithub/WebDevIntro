◉JavaScriptとは

JavaScriptは、Webページに処理や動きを加えるためのプログラミング言語です。

HTMLページの構造・内容を記述する
CSS色・大きさ・配置など見た目を指定する
JavaScript操作に応じて処理し、ページを書き換える

HTMLはマークアップ言語、CSSはスタイルシート言語、JavaScriptはプログラミング言語です。名前は似ていますが、JavaとJavaScriptは別の言語です。JavaScriptを「Java」と略したり、同じ言語として扱ったりしないようにしましょう。

▤ JavaScriptを書いてみよう

JavaScriptは、HTMLの中にある <script> タグを使って実行できます。 まずは、メッセージをコンソールに表示してみましょう。

index.html
<script>
  console.log("Hello world!!");
</script>

コードの意味

  • <script>：JavaScriptを書く場所を示すタグ
  • console.log()：値やメッセージをコンソールに出力する命令
  • "Hello world!!"：出力する文字列

コンソールで実行結果を確認しよう

console.log() の出力は、Webページ上には直接表示されません。 ブラウザに用意されている「開発者ツール」を使って確認します。

  1. 作成した index.html をブラウザで開きます。
  2. ページ上で右クリックし、「検証」を選択します。
  3. 開発者ツールの「Console（コンソール）」タブを開きます。
  4. Hello world!! と表示されていることを確認します。

Windowsでは、F12 または Ctrl + Shift + J でもコンソールを開けます。 ブラウザによって操作方法が異なる場合があります。

index.html
<script>
  console.log("Hello world!!");
  console.log(123);
  console.log(10 + 20);
</script>

Console の表示例

> Hello world!!
> 123
> 30

文字列だけでなく、数値や計算結果も出力できます。 プログラムが正しく動いているか調べるときにも便利です。

補足：scriptタグはどこに書く？

<script> タグはHTMLの中に記述できます。 今回は、ページの内容を書いたあとに実行する形で、 </body> の直前に置いてみましょう。

index.html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>JavaScript入門</title>
</head>
<body>
  <h1>はじめてのJavaScript</h1>

  <script>
    console.log("JavaScriptが実行されました！");
  </script>
</body>
</html>

HTMLがページの構造を作り、<script> の中の JavaScriptが処理を実行します。 次は、変数や条件分岐を使って、さまざまな処理を書いてみましょう。

∑ 変数と基本的なプログラミング

JavaScriptでは、数値の計算や条件による処理の分岐、繰り返し処理など、 ほかのプログラミング言語と同じような処理を書くことができます。 まずは、基本的な書き方を確認していきましょう。

1. 変数を使ってみよう

プログラムでは、数値や文字列などのデータを「変数」に保存できます。 JavaScriptでは、主に const と let を使って変数を宣言します。

JavaScript
let score = 80;
const name = "Alice";

console.log(score);
console.log(name);

score = 95;
console.log(score);

実行結果

> 80
> Alice
> 95
  • let：あとから値を変更できる変数を宣言します。
  • const：変数への再代入ができないように宣言します。
  • =：右辺の値を左辺の変数に代入します。

今回は、基本的に値を変更しない場合は const、 値を変更する場合は let を使いましょう。 なお、const で宣言した変数は、あとから別の値を代入できません。

2. 基本的な計算をしてみよう

JavaScriptでは、算数で使う四則演算をそのままプログラムで扱えます。 変数に保存した数値を使って計算することもできます。

JavaScript
let a = 5;
let b = 3;

console.log(a + b); // 足し算
console.log(a - b); // 引き算
console.log(a * b); // 掛け算
console.log(a / b); // 割り算
console.log(a % b); // 余り

a++;
console.log(a);     // 1増やす

実行結果

> 8
> 2
> 15
> 1.6666666666666667
> 2
> 6

+、-、*、/ は それぞれ足し算、引き算、掛け算、割り算を表します。 % は割り算の余りを求める演算子です。 また、a++ は変数 a の値を1増やします。

このほか、a += 2 は a = a + 2 と同じ意味です。 このような省略した書き方も、プログラムではよく使われます。

3. 条件によって処理を変えよう

if 文を使うと、条件に応じて実行する処理を変えられます。 条件が成立したときだけ処理を実行したり、複数の条件を順番に判定したりできます。

JavaScript
const score = 75;

if (score >= 80) {
  console.log("Great!");
} else if (score >= 60) {
  console.log("Pass!");
} else {
  console.log("Try again!");
}

実行結果

> Pass!
  • if：最初の条件を判定します。
  • else if：前の条件が成立しなかった場合に、別の条件を判定します。
  • else：どの条件も成立しなかった場合に実行します。

条件には、>、<、>=、 <= などの比較演算子を使えます。 また、等しいかどうかを比較する場合は === を使います。

JavaScriptでの注意点

JavaScriptには == と === があります。 == は比較の際に型変換が行われることがありますが、 === は型も含めて比較します。 例えば、5 == "5" は true ですが、 5 === "5" は false です。 基本的には === を使うようにしましょう。

4. 繰り返し処理を使おう

同じような処理を何度も実行したいときは、繰り返し処理を使います。 for 文では、回数を数えながら処理を繰り返せます。

JavaScript
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

実行結果

> 1
> 2
> 3
> 4
> 5

for 文の括弧の中には、初期化、繰り返し条件、更新処理を記述します。

  • let i = 1：変数 i を1で初期化します。
  • i <= 5：この条件が成立している間、繰り返します。
  • i++：1回処理するごとに i を1増やします。

5. 配列と拡張for文

複数のデータをまとめて扱うには、配列を使います。 JavaScriptでは、配列の要素を順番に取り出すために for...of という書き方も利用できます。

JavaScript
const fruits = ["Apple", "Orange", "Grape"];

for (const fruit of fruits) {
  console.log(fruit);
}

実行結果

> Apple
> Orange
> Grape

for...of は、配列などから要素を1つずつ取り出して処理します。 要素の番号を自分で管理しなくてもよいため、単純にすべての要素を処理したい場合に便利です。

通常の for 文は繰り返す回数や添字を制御したい場合に、 for...of は要素そのものを順番に処理したい場合に使い分けましょう。

ƒ 関数を使ってみよう

JavaScriptの関数は、C言語の関数と同じように使うことができます。また、JavsScript固有の書き方があるので、いくつかの方法を紹介します。

1. 関数を定義する

JavaScriptでは、function を使って関数を定義できます。 例えば、時・分・秒を合計の秒数に変換する関数は、次のように書けます。

index.html
<script>
  function toSeconds(hour, min, sec) {
    const answer = hour * 3600 + min * 60 + sec;
    return answer;
  }
</script>
  • function toSeconds(...)：toSeconds という名前の関数を定義します。
  • hour, min, sec：関数に渡す値を受け取るための引数です。
  • return answer：計算結果を関数の呼び出し元に返します。

ただし、関数を定義しただけでは、計算は実行されません。 実際に使うには、関数を呼び出す必要があります。

2. 関数を呼び出す

関数名の後ろに括弧を書き、引数を渡すことで関数を呼び出せます。 戻り値を console.log() に渡せば、計算結果をコンソールで確認できます。

index.html
<script>
  let hour = 23;
  let minute = 59;
  let second = 59;

  function toSeconds(hour, min, sec) {
    const answer = hour * 3600 + min * 60 + sec;
    return answer;
  }

  console.log(toSeconds(hour, minute, second));
</script>

実行結果

> 86399

例えば、toSeconds(1, 30, 0) は1時間30分0秒を表し、 戻り値として 5400 を返します。 このように、同じ関数に異なる引数を渡して、何度でも利用できます。

3. console.log() と return の違い

console.log() は値をコンソールに表示し、 return は値を関数の呼び出し元に返します。 この2つは役割が異なります。

JavaScript
function add(a, b) {
  console.log(a + b);
}

const result = add(10, 20);
console.log(result);

実行結果

> 30
> undefined

関数内で 30 を表示しても、戻り値は自動的には設定されません。 return を書いていない関数は、通常 undefined を返します。

4. 関数には複数の書き方がある

JavaScriptでは、function による定義以外にも、 関数式やアロー関数を使って関数を定義できます。

関数式
const toSeconds = function(hour, min, sec) {
  return hour * 3600 + min * 60 + sec;
};

console.log(toSeconds(1, 30, 0)); // 5400

関数式では、関数を変数に代入しています。 次に紹介するアロー関数も、同じように変数へ代入して利用できます。

5. アロー関数

アロー関数は、=> を使って関数を定義する書き方です。 Web開発では、イベント処理やコールバック関数などでよく使われます。

① 通常のアロー関数

JavaScript
const add = (a, b) => {
  return a + b;
};

console.log(add(3, 5));

実行結果

> 8

return で計算結果を返します。 複数の処理を実行したい場合にも、この書き方を使えます。

② 式を返す場合

JavaScript
const add = (a, b) => a + b;

console.log(add(3, 5));

実行結果

> 8

処理が1つの式だけなら、{} と return を省略できます。 式の評価結果が、そのまま戻り値になります。

③ 引数が1つの場合

JavaScript
const double = n => n * 2;

console.log(double(5));

実行結果

> 10

引数が1つの場合は、引数を囲む () を省略できます。

④ 引数が0個の場合

JavaScript
const sayHello = () => "Hello!";

console.log(sayHello());

実行結果

> Hello!

引数がない場合は、() を省略できません。

⑤ オブジェクトを返す場合

JavaScript
const makePoint = (x, y) => ({ x: x, y: y });

console.log(makePoint(3, 5));

実行結果

> { x: 3, y: 5 }

オブジェクトを返す場合は、({ ... }) のように () で囲みます。 オブジェクトのプロパティ名と変数名が同じ場合は、 ({ x, y }) と省略して書くこともできます。

6. デフォルト引数

引数には、値が省略された場合に使用するデフォルト値を設定できます。 例えば、分や秒が省略された場合に、それぞれ0として扱うことができます。

JavaScript
function toSeconds(hour, min = 0, sec = 0) {
  return hour * 3600 + min * 60 + sec;
}

console.log(toSeconds(1));
console.log(toSeconds(1, 30));
console.log(toSeconds(1, 30, 5));

実行結果

> 3600
> 5400
> 5405

デフォルト値を設定しておけば、必要な引数だけを指定して関数を呼び出せます。

7. コールバック関数

JavaScriptでは、関数を別の関数の引数として渡すことができます。 渡された関数が、特定のタイミングで呼び出される仕組みを利用した関数を コールバック関数 と呼びます。

例えば、setTimeout() は指定した時間が経過したあとに、 渡された関数を実行します。

JavaScript
setTimeout(() => {
  console.log("3秒経過しました！");
}, 3000);

実行結果

> （3秒後）
> 3秒経過しました！

() => { ... } の部分がコールバック関数です。 これを setTimeout() に渡すことで、3秒後に実行されるようになります。

↗イベントと入力値

クリックや入力など、ユーザーの操作をきっかけに処理を実行できます。このような出来事をイベントと呼びます。今回は addEventListener("click", ...) でクリック時の処理を登録します。

index.html + JavaScript の例
<button id="hello">Click Me!!</button>
<script>
document.getElementById("hello")
  .addEventListener("click", () => {
    alert("Hello!!");
  });
</script>

実行例

ボタンをクリックして、ダイアログを表示してみましょう。

入力した文字列を表示する

JavaScript のポイント
const nameInput =
  document.getElementById("name-input");

button.addEventListener("click", () => {
  result.textContent = nameInput.value;
});

実際に入力してみよう

ここに結果が表示されます。

document.getElementById()でIDに対応する要素を取得し、入力欄の .value から値を読み取ります。.textContent は要素内のテキストを変更します。

ポイント： 入力欄の value は文字列です。数値として計算したい場合は Number(input.value) のように変換します。

ブラウザはHTMLを、要素同士の親子関係を持つ構造として扱います。この仕組みをDOM（Document Object Model）と呼びます。

HTML

＋少しだけ発展：エラーと通信

エラーが発生したときは、try / catchで処理できます。まずは、ブラウザの開発者ツールに出るエラーメッセージを確認する習慣を付けましょう。

エラー処理の例
try {
  notDefinedFunction();
} catch (error) {
  console.log("エラーが発生しました。");
}

また、JavaScriptは fetch() を使ってサーバーからデータを取得することもできます。こうした非同期通信を利用すると、ページ全体を再読み込みせずに情報を更新するWebアプリケーションを作れます。API通信の詳細は後続の講習で扱います。

✎演習問題 — コードを読んで、続きを完成させよう

それぞれの問題は、まずコードを読み、「何が起きるか」を予想してから実行してください。空欄を埋める問題では、コードを全部書き直さず、指定された部分だけを変更します。

進め方： ①コードを読む → ②結果を予想する → ③空欄を埋める → ④実行して確認する。迷ったら、直前の説明を読み返しましょう。
1

Hello, world!

コンソールに自分の名前を表示してください。文字列を指定する部分を変更します。

問題のコードを開く 
const name = "ここを変更";
console.log("Hello, " + name);

ヒント：文字列は引用符で囲みます。

2

2つの数の計算

2つの数値の合計が表示されるように、演算子を変更してください。

問題のコードを開く 
const a = 12;
const b = 8;
console.log(a ここを変更 b);

ヒント：足し算の演算子を使います。

3

条件分岐

点数が60以上なら「合格」と表示されるように、条件式を完成させます。

問題のコードを開く 
const score = 72;
if (score ここを変更 60) {
  console.log("合格");
} else {
  console.log("もう少し！");
}

ヒント：「以上」を表す比較演算子は何でしょう？

4

入力文字列を表示

入力欄の値を取得し、ページ内に表示するコードを完成させます。

問題のコードを開く 
const input = document.getElementById("word");
const result = document.getElementById("result");
document.getElementById("show").addEventListener("click", () => {
  result.textContent = input.ここを変更;
});

ヒント：入力欄の値を取り出すプロパティです。

5

DOMを書き換える

ボタンを押したら見出しの文章が変わるように、代入するテキストを変更します。

問題のコードを開く 
const title = document.getElementById("title");
document.getElementById("change").addEventListener("click", () => {
  title.textContent = ここを変更;
});

ヒント：表示したい文章を文字列で指定します。

6

表示を切り替える

ボタンを押すたびに表示と非表示を切り替える条件を完成させます。

問題のコードを開く 
if (message.hidden) {
  message.hidden = false;
} else {
  message.hidden = ここを変更;
}

ヒント：表示する場合はfalse、隠す場合はtrueです。
