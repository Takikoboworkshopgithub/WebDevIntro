◉JavaScriptとは

JavaScriptは、Webページに処理や動きを加えるためのプログラミング言語です。

HTMLページの構造・内容を記述する
CSS色・大きさ・配置など見た目を指定する
JavaScript操作に応じて処理し、ページを書き換える

HTMLはマークアップ言語、CSSはスタイルシート言語、JavaScriptはプログラミング言語です。名前は似ていますが、JavaとJavaScriptは別の言語です。

▤JavaScriptを書いてみよう

JavaScriptはHTMLの中にある <script> タグの内部に記述できます。まずは、HTMLファイル全体を見てみましょう。

index.html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>JavaScript入門</title>
</head>
<body>
  <h1>はじめてのJavaScript</h1>

  <script>
    console.log("JavaScriptが実行されました！");
  </script>
</body>
</html>

この例では、<body> 内にある <script> と </script> の間にJavaScriptを書いています。ブラウザはHTMLを読み込みながら、この部分のJavaScriptを実行します。

console.log()で出力する

console.log() は、値や文字列を開発者ツールのコンソールに出力する命令です。C言語の printf() などに近い、デバッグや動作確認に使う出力手段です。ただし、Webページ上に文字を表示する命令ではありません。

JavaScript
console.log("Hello world!!");
console.log(123);
console.log(10 + 20);

Console の表示例

> Hello world!!
> 123
> 30

コンソールを確認するには、ブラウザでページを開き、右クリックから「検証」を選択してConsoleタブを開きます。Windowsでは F12 や Ctrl + Shift + J でも開けます。

文字列だけでなく、数値や計算式も渡せます。複数の値をカンマ区切りで渡すこともできます。

JavaScript
const name = "Alice";
const score = 95;

console.log("name:", name, "score:", score);

∑変数と基本的なプログラミング

JavaScriptにも、変数、演算子、条件分岐、繰り返し処理など、ほかのプログラミング言語と共通する仕組みがあります。一方で、変数の宣言方法や型の扱いにはJavaScript特有の特徴があります。

1. 変数と型

変数は let または const で宣言します。JavaScriptは動的型付け言語であり、変数を宣言するときに型を指定する必要はありません。代入された値に応じて、その値の型が決まります。

JavaScript
let score = 80;
const name = "Alice";

console.log(score);
console.log(name);

// name = "Bob"; // constへの再代入はエラー
score = 95;
console.log(score);

実行結果

> 80
> Alice
> 95
  • let：あとから別の値を再代入できる変数を宣言します。
  • const：あとから別の値を再代入できない変数を宣言します。

値を変更する必要がなければ、基本的に const を使います。再代入が必要な場合に let を選ぶ、という順序で考えるとよいでしょう。

2. 算術演算子

四則演算や剰余などの演算子は、ほかの多くの言語と同様に使用できます。

JavaScript
let a = 5;
let b = 3;

console.log(a + b); // 足し算
console.log(a - b); // 引き算
console.log(a * b); // 掛け算
console.log(a / b); // 割り算
console.log(a % b); // 余り

a++;
console.log(a);     // 1増やす

実行結果

> 8
> 2
> 15
> 1.6666666666666667
> 2
> 6

+、-、*、/ はそれぞれ加算、減算、乗算、除算を表します。% は剰余演算子です。また、a++ は変数 a の値を1増やします。a += 2 のような複合代入演算子も利用できます。

3. if文

JavaScriptにも if、else if、else があり、条件に応じて処理を分岐できます。比較演算子も、ほかの多くの言語と同じように使用できます。

JavaScript
const score = 75;

if (score >= 80) {
  console.log("Great!");
} else if (score >= 60) {
  console.log("Pass!");
} else {
  console.log("Try again!");
}

実行結果

> Pass!

if で最初の条件を判定し、成立しなければ else if の条件を順番に判定します。どの条件も成立しなかった場合は else の処理が実行されます。

4. for文

回数や添字を管理しながら繰り返す場合は、通常の for 文を使います。

JavaScript
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

実行結果

> 1
> 2
> 3
> 4
> 5

括弧の中には、初期化式、継続条件、更新式を記述します。この例では i を1から始め、i <= 5 が成立する間、処理を繰り返します。

5. 配列とfor...of

配列の要素を順番に取り出す場合は、for...of を利用できます。C++の範囲for文やPythonのfor文に近い書き方です。

JavaScript
const fruits = ["Apple", "Orange", "Lemon"];

for (const fruit of fruits) {
  console.log(fruit);
}

実行結果

> Apple
> Orange
> Lemon

for...of は、配列などの反復可能なオブジェクトから要素を1つずつ取り出します。添字を使う必要がない場合に便利です。添字を直接操作したい場合は通常の for 文を使います。

{ }オブジェクトと連想配列

C++の map やPythonの dict のように、キーと値を対応付けて管理するデータ構造もJavaScriptにあります。JavaScriptでは、オブジェクトや Map を利用できます。ここでは、まずオブジェクトを見てみましょう。

配列を2つ使って管理する場合

例えば、果物の名前と価格を別々の配列で管理するとします。Lemonの価格を探すには、名前の配列を順番に調べ、同じ添字にある価格を取り出す必要があります。

JavaScript
const fruitNames = ["Apple", "Orange", "Lemon"];
const fruitPrices = [170, 90, 110];

let lemonPrice;

for (let i = 0; i < fruitNames.length; i++) {
  if (fruitNames[i] === "Lemon") {
    lemonPrice = fruitPrices[i];
    break;
  }
}

console.log(lemonPrice); // 110

この方法では、2つの配列の対応関係を常に保つ必要があります。また、名前を探す処理は配列を先頭から調べるため、要素数を N とすると最悪の場合 O(N) の時間がかかります。

オブジェクトでキーと値を対応付ける

オブジェクトを使うと、キーと値をひとまとまりに管理できます。左側がキー（key）、右側が値（value）です。

JavaScript
const fruits = {
  apple: 170,
  orange: 90,
  lemon: 110
};

console.log(fruits["lemon"]);
console.log(fruits.lemon);

実行結果

> 110
> 110

この例では、果物の名前をキー、価格を値として管理しています。角括弧を使った fruits["lemon"] と、ドットを使った fruits.lemon は、どちらも同じプロパティを参照します。

オブジェクトのプロパティ参照は、平均 O(1) と高速です。

なお、キーを動的に指定したい場合や、任意の型をキーとして使いたい場合には Map も利用できます。

Mapの例
const prices = new Map();

prices.set("apple", 170);
prices.set("orange", 90);
prices.set("lemon", 110);

console.log(prices.get("lemon")); // 110

≡値がない状態と等価演算子

1. undefinedとnull

JavaScriptには、「値が存在しない」状態を表す値として undefined と null があります。どちらも値がないことに関係しますが、意味合いが異なります。

  • undefined：値がまだ割り当てられていない、または存在しないプロパティを参照した場合などに現れます。
  • null：値が存在しないことを、プログラム側で明示的に表すために使います。
JavaScript
let name;
console.log(name); // undefined

let user = null;
console.log(user); // null

実行結果

> undefined
> null

例えば、C言語ではポインタが何も指していない状態を NULL で表します。JavaScriptにはポインタを直接扱う仕組みはありませんが、データが未設定なのか、意図的に空として扱われているのかを区別するために、これらの値を使います。

比較項目 undefined null
意味 値が未設定・未定義 意図的に値がない
設定する主体 主にJavaScriptが自動的に設定 主に開発者が明示的に設定
typeofの結果 "undefined" "object"
例 宣言後に値を代入していない変数 let user = null;

typeof null が "object" になるのは、JavaScriptの歴史的な仕様に由来する例外です。null が通常のオブジェクトであるという意味ではありません。

2. ==と===

JavaScriptには、等価性を比較する演算子として == と === があります。両者の違いは、比較の際に型変換を行うかどうかです。

JavaScript
let a = "1";
let b = 1;

console.log(a == b);
console.log(a === b);

実行結果

> true
> false
  • ==：必要に応じて型変換を行ってから比較します。
  • ===：型変換を行わず、型と値の両方を比較します。

例えば、文字列の "1" と数値の 1 は、== では等しいと判定されますが、=== では型が異なるため等しくありません。

比較の例
console.log(true == 1);          // true
console.log(true === 1);         // false

console.log(null == undefined);  // true
console.log(null == 0);          // false
console.log(undefined == false); // false

console.log(1 === "1");          // false
console.log(true === 1);         // false
console.log(null === undefined);// false

型変換を伴う比較は、意図しない判定につながる場合があります。そのため、通常は === を使い、必要な型変換は明示的に行うことをおすすめします。

==を使う例外的なケース

null と undefined のどちらであっても「値がない」として扱いたい場合には、value != null という比較が利用できます。この式は、値が null でも undefined でもない場合に true になります。

JavaScript
if (value != null) {
  // valueはnullでもundefinedでもない
}

これは == の特殊な比較規則を利用した書き方です。一般的な比較では === を使い、このように意図が明確な場合に限って == を使うとよいでしょう。

ƒ 関数を使ってみよう

JavaScriptの関数は、C言語の関数と同じように使うことができます。また、JavsScript固有の書き方があるので、いくつかの方法を紹介します。

1. 関数を定義する

JavaScriptでは、function を使って関数を定義できます。 例えば、時・分・秒を合計の秒数に変換する関数は、次のように書けます。

index.html
<script>
  function toSeconds(hour, min, sec) {
    const answer = hour * 3600 + min * 60 + sec;
    return answer;
  }
</script>
  • function toSeconds(...)：toSeconds という名前の関数を定義します。
  • hour, min, sec：関数に渡す値を受け取るための引数です。
  • return answer：計算結果を関数の呼び出し元に返します。

ただし、関数を定義しただけでは、計算は実行されません。 実際に使うには、関数を呼び出す必要があります。

2. 関数を呼び出す

関数名の後ろに括弧を書き、引数を渡すことで関数を呼び出せます。 戻り値を console.log() に渡せば、計算結果をコンソールで確認できます。

index.html
<script>
  let hour = 23;
  let minute = 59;
  let second = 59;

  function toSeconds(hour, min, sec) {
    const answer = hour * 3600 + min * 60 + sec;
    return answer;
  }

  console.log(toSeconds(hour, minute, second));
</script>

実行結果

> 86399

例えば、toSeconds(1, 30, 0) は1時間30分0秒を表し、 戻り値として 5400 を返します。 このように、同じ関数に異なる引数を渡して、何度でも利用できます。

3. console.log() と return の違い

console.log() は値をコンソールに表示し、 return は値を関数の呼び出し元に返します。 この2つは役割が異なります。

JavaScript
function add(a, b) {
  console.log(a + b);
}

const result = add(10, 20);
console.log(result);

実行結果

> 30
> undefined

関数内で 30 を表示しても、戻り値は自動的には設定されません。 return を書いていない関数は、通常 undefined を返します。

4. 関数には複数の書き方がある

JavaScriptでは、function による定義以外にも、 関数式やアロー関数を使って関数を定義できます。

関数式
const toSeconds = function(hour, min, sec) {
  return hour * 3600 + min * 60 + sec;
};

console.log(toSeconds(1, 30, 0)); // 5400

関数式では、関数を変数に代入しています。 次に紹介するアロー関数も、同じように変数へ代入して利用できます。

5. アロー関数

アロー関数は、=> を使って関数を定義する書き方です。 Web開発では、イベント処理やコールバック関数などでよく使われます。

① 通常のアロー関数

JavaScript
const add = (a, b) => {
  return a + b;
};

console.log(add(3, 5));

実行結果

> 8

return で計算結果を返します。 複数の処理を実行したい場合にも、この書き方を使えます。

② 式を返す場合

JavaScript
const add = (a, b) => a + b;

console.log(add(3, 5));

実行結果

> 8

処理が1つの式だけなら、{} と return を省略できます。 式の評価結果が、そのまま戻り値になります。

③ 引数が1つの場合

JavaScript
const double = n => n * 2;

console.log(double(5));

実行結果

> 10

引数が1つの場合は、引数を囲む () を省略できます。

④ 引数が0個の場合

JavaScript
const sayHello = () => "Hello!";

console.log(sayHello());

実行結果

> Hello!

引数がない場合は、() を省略できません。

⑤ オブジェクトを返す場合

JavaScript
const makePoint = (x, y) => ({ x: x, y: y });

console.log(makePoint(3, 5));

実行結果

> { x: 3, y: 5 }

オブジェクトを返す場合は、({ ... }) のように () で囲みます。 オブジェクトのプロパティ名と変数名が同じ場合は、 ({ x, y }) と省略して書くこともできます。

6. デフォルト引数

引数には、値が省略された場合に使用するデフォルト値を設定できます。 例えば、分や秒が省略された場合に、それぞれ0として扱うことができます。

JavaScript
function toSeconds(hour, min = 0, sec = 0) {
  return hour * 3600 + min * 60 + sec;
}

console.log(toSeconds(1));
console.log(toSeconds(1, 30));
console.log(toSeconds(1, 30, 5));

実行結果

> 3600
> 5400
> 5405

デフォルト値を設定しておけば、必要な引数だけを指定して関数を呼び出せます。

↗イベント

JavaScriptでは、マウス操作やキー操作、ブラウザーの動作などを感知し、 それに応じて処理を実行できます。このような出来事を イベントと呼びます。

  • マウス操作：クリックやポインタの移動など
  • キー操作：キーの押下や文字の入力など
  • ブラウザー操作：ページの読み込みやスクロールなど

例えば、ボタンを押したら音を出す、下にスクロールしたら色が変わっていく、 といった動きも実装できます。

今まで学習してきたCやC++では、基本的に main関数の上から下に向かって順番に処理が実行されていました。 一方、JavaScriptでは、イベントに対する処理をあらかじめ登録しておき、 イベントが発生したときに対応する処理を実行するという仕組みをよく利用します。

このように、イベントをきっかけとして処理が実行される仕組みを イベント駆動型プログラミングと呼びます。 イベントが発生して処理が実行されることを「発火する」と表現することもあります。

このようなイベントに応じて呼び出される関数を コールバック関数と呼びます。 また、イベントを監視し、対応する処理を登録する仕組みを イベントリスナーと呼びます。

実際にイベントを使ってみよう

まずは、ボタンを押したときにメッセージを表示する簡単なプログラムを見てみましょう。 HTMLのbuttonタグにonclick属性を指定すると、 ボタンがクリックされたときに関数を実行できます。

HTML + JavaScript
<button onclick="hello()">
  Click Me!!
</button>

<script>
  function hello() {
    alert("Hello!!");
  }
</script>

実行例

ボタンをクリックして、ダイアログを表示してみましょう。

この例では、ボタンがクリックされたときにhello()関数が呼び出されます。 このように、イベントを利用することで、ユーザーの操作に応じてWebページの動きを変えられます。

▣DOM・エレメント

DOMとは

HTMLは、要素同士の親子関係を持つ木構造として扱うことができます。 例えば、次のHTMLを考えてみましょう。

HTML
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <title>Document</title>
  </head>
  <body>
    <h1>自己紹介</h1>
    <p>こん！</p>
  </body>
</html>

HTMLの構造

HTMLの要素は親子関係を持つ木構造として表現できます。

この場合、bodyの子要素はh1とpです。 このような木構造をDOMツリーと呼びます。

DOM（Document Object Model）は、このDOMツリーを通してHTMLの各要素を JavaScriptから取得・操作できるようにする仕組みです。 各要素はElement（エレメント）というオブジェクトとして扱われ、 文章やCSSなどの内容を変更できます。

エレメントを取得して変更する

実際のコードを見てみましょう。 まずは、HTMLのpタグを取得して、文字色を変更してみます。

HTMLのbuttonタグにonclick属性を指定し、 ボタンが押されたときに関数が実行されるようにします。

HTML + JavaScript
<p>1つ目の段落です。</p>
<p>2つ目の段落です。</p>

<button onclick="changeParagraphs()">
  pタグの色を変える
</button>

<script>
  function changeParagraphs() {
    // "p"というタグ名を持つエレメントをすべて集めてくる
    const pList = document.getElementsByTagName('p');

    // 集めた中の1番目（0番目）の文字色を赤にする
    pList[0].style.color = 'red';

    // 集めた中の2番目（1番目）の文字色を青にする
    pList[1].style.color = 'blue';
  }
</script>

実行例

1つ目の段落です。

2つ目の段落です。

document.getElementsByTagName('p')は、 指定したタグ名を持つエレメントをすべて取得するメソッドです。 取得したエレメントはリストのように扱うことができ、 pList[0]やpList[1]のように番号を指定してアクセスできます。

また、.style.colorを変更することで、文字色を変更できます。 このように、document.getElementsBy...などを使って要素を取得し、 JavaScriptから動的に変更することができます。

基本的なプログラミングと組み合わせる

もちろん、これまで学習してきた変数や条件分岐などと組み合わせることもできます。 例えば、ボタンを押すたびに文字色を切り替えるプログラムは次のようになります。

HTML + JavaScript
<p>1つ目の段落です。</p>
<p>2つ目の段落です。</p>

<button onclick="changeParagraphs()">
  pタグの色を変える
</button>

<script>
  let button_click_number = 0;

  function changeParagraphs() {
    const pList = document.getElementsByTagName('p');

    if (button_click_number === 0) {
      button_click_number++;

      pList[0].style.color = 'red';
      pList[1].style.color = 'blue';
    } else {
      pList[0].style.color = 'black';
      pList[1].style.color = 'black';

      button_click_number = 0;
    }
  }
</script>

実行例

1つ目の段落です。

2つ目の段落です。

ボタンを押すと文字色が赤と青になり、もう一度押すと元の黒色に戻ります。 このように、イベントと基本的なプログラミングを組み合わせることで、 さまざまな動きを実装できます。

IDを指定してエレメントを取得する

実際には、タグ名を指定してすべての要素を取得するよりも、 HTMLのタグにidを付けて、特定の要素にアクセスする方法もよく利用されます。

HTML + JavaScript
<p id="my-text">
  ボタンを押すと、この文字が緑色になります。
</p>

<button id="my-button">
  色を変える！
</button>

<script>
  // 1. 操作したいエレメントを取得する
  const myButton = document.getElementById('my-button');
  const myText = document.getElementById('my-text');

  // 2. ボタンがクリックされたときのイベントを設定する
  myButton.addEventListener('click', function () {
    // p要素の文字色を緑にする
    myText.style.color = 'green';
  });
</script>

実行例

ボタンを押すと、この文字が緑色になります。

document.getElementById()は、指定したIDを持つエレメントを取得するメソッドです。

また、ここでは先ほどのonclick属性ではなく、 addEventListener()を使っています。 これはJavaScript側でイベントを登録する方法で、HTMLとJavaScriptの処理を分けて記述できます。 実際のWeb開発では、この方法がよく利用されます。

addEventListener()の第1引数にはイベントの種類を指定し、 第2引数にはイベント発生時に実行するコールバック関数を指定します。 今回は'click'を指定しているため、クリック時に処理が実行されます。

formを使った足し算アプリ

次に、formタグを利用して、簡単な足し算をしてみましょう。 2つの入力欄に数字を入力し、ボタンを押すと計算結果が表示されるプログラムです。

HTML + JavaScript
<form>
  <input type="number" id="num1" />
</form>

<form>
  <input type="number" id="num2" />
</form>

<button id="my-button">計算</button>

<p id="result"></p>

<script>
  const myButton = document.getElementById('my-button');

  myButton.addEventListener('click', () => {
    const num1 = document.getElementById('num1').value;
    const num2 = document.getElementById('num2').value;

    const result = Number(num1) + Number(num2);

    document.getElementById('result').textContent = result;
  });
</script>

ここに計算結果が表示されます。

このプログラムでは、ボタンがクリックされたときに2つの入力欄から値を取得し、 足し算を行っています。 ただし、inputから取得したvalueは文字列なので、 Number()を使って数値に変換しています。

もっとシンプルに書いてみよう

先ほどのプログラムは、addEventListener()を利用して記述しましたが、 最初に紹介したonclick属性を使うと、次のようにもっとシンプルに書くこともできます。

HTML + JavaScript
<form>
  <input type="number" id="num1">
</form>

<form>
  <input type="number" id="num2">
  <button type="button" onclick="calc()">
    計算
  </button>
</form>

<p id="result"></p>

<script>
  function calc() {
    const a = Number(document.getElementById("num1").value);
    const b = Number(document.getElementById("num2").value);

    document.getElementById("result").textContent = a + b;
  }
</script>

実際に計算してみよう

ここに計算結果が表示されます。

このように、HTMLで入力欄やボタンを用意し、JavaScriptで値を取得・計算・表示することで、 簡単なWebアプリケーションを作ることができます。

今回のポイント：
  • イベントは、ユーザーの操作やブラウザーの動作をきっかけに発生する。
  • DOMを通して、JavaScriptからHTMLの要素を取得・変更できる。
  • getElementById()でIDを指定して要素を取得できる。
  • addEventListener()でイベントに対する処理を登録できる。
  • valueで入力値を取得し、textContentで文章を変更できる。
